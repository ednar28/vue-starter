# vue-starter

This template is used to simplify the initial setup of a Vue project. It has already included all the necessary dependencies and configurations to get you started quickly.

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.

## Getting Started

### Install Dependencies

```sh
bun install
```

### Run Development Server

```sh
bun run dev
```

## Scripts

Below are the scripts which are available via `npm run`.

- `dev`: Starts the development server.
- `build`: Builds the application for production.
- `preview`: Starts a production-like server for previewing the built application.
- `build-only`: Builds the application for production without generating a preview server.
- `type-check`: Runs type checking on the application.
- `lint`: Runs eslint to lint the application.
